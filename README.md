# ReplayLog

검색 로그의 중복 전달과 수집 프로세스 종료 후 재실행을 다루는 Python/SQLite 프로젝트입니다.

개발 순서는 기대 결과와 테스트 작성, 실패 확인, 구현, 재실행 및 강제 종료 검증입니다. 현재 구현 전 테스트를 먼저 작성하고 있습니다.

설계 규칙은 [설계 문서](docs/DESIGN.md), 직접 계산한 입력과 정답은 [fixtures](fixtures)에 있습니다.

```text
python -m unittest discover -s tests -v
```

문제 정의와 설계 검토는 사용자와 협의하고, 구현과 테스트 작성에는 AI 에이전트를 활용합니다. 설계상의 기대 결과와 실제 실행 결과를 구분해 기록합니다.
